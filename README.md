# artificialRemapping

This repository contains analysis code and processed data for the figures associated with the following paper: "Reproducible and predictable reorganization of place fields driven by grid subfield rate changes" by Lykken, Kanter, Kaslow, Chadney, Asumbisa, Descamps & Kentros (2026). The manuscript is available on bioRxiv. DOI: https://doi.org/10.64898/2026.02.10.705142

The repository contains:
- Code to plot main and supplementary figures of the paper.
- Pre-processed data and code required to generate those figures.

Note that the data provided here is intended only for reproducing the paper figures.

The folder structure is as follows:
- data: pre-processed data required to generate figures, organized by brain region
- figures: code used to generate figures, organized by figure number
- helpers: extra code dependencies

Any questions should be sent to the corresponding author of the paper, Christine M. Lykken (christine.lykken@ntnu.no)
